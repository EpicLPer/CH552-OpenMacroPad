Select a key

Sends a key position directly, for anything without a name here. Usage 52 is the key a US layout calls apostrophe, which a German layout uses for ä.

The pad sends key positions, not characters, so what actually gets typed depends on the keyboard layout the host is set to.

Windows handles some chords itself and will not pass them on, the Windows key especially. Tick the modifiers by hand for those.
