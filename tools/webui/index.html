Firmware

Chrome and Edge update a pad that is already running 1.2.0. Firmware 1.0.0 and 1.1.0 have no updater command. Connect names that firmware and the one-time chflash of padfw-1.2.0.bin (13296 bytes).

Choose the rebuilt padfw-1.2.0.web.bin, not the full recovery file and not an older .web.bin.

Select a key

Sends that key position and ignores the computer's layout. Use it for a key that has no name here. Named characters and shortcuts above already follow the layout selected at the top.

A captured character is stored as that character, so @ and Ctrl+Z come out right on US, UK, German and French computers. Set the computer's layout above; the pad cannot see it by itself.

Windows handles some chords itself and will not pass them on, the Windows key especially. Tick the modifiers by hand for those.
